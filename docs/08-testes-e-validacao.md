## Validação

**Como foi verificado se a solução realmente ajuda?**

> Testar verifica se o sistema funciona. **Validar** verifica se o sistema resolve o problema para quem é afetado.

Possibilidades:

- teste com usuários;
- questionário;
- teste de usabilidade;
- comparação antes/depois;
- redução de tempo;
- melhoria de processo;
- precisão;
- indicadores;
- simulações.
