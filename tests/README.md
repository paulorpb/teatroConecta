# Testes (`tests/`)

Esta pasta reúne os **testes** e os **cenários de validação** do MVP.

> **Avaliação:** AV2. Os resultados devem ser registrados em [08-testes-e-validacao.md](../docs/08-testes-e-validacao.md).

## O que pode existir aqui

- **testes unitários** — verificam partes isoladas do código (funções, classes);
- **testes de integração** — verificam a comunicação entre partes do sistema (por exemplo, API e banco de dados);
- **testes manuais** — roteiros passo a passo executados por uma pessoa;
- **scripts** — automatizações para executar testes ou preparar dados de teste;
- **cenários de validação** — roteiros usados em testes com usuários, questionários e simulações.

## Roteiro de teste manual (modelo)

> Copie este modelo para um novo arquivo (por exemplo, `teste-manual-T01.md`) para cada cenário.

```markdown
# T01 — Nome do cenário

- Requisito relacionado:
- Pré-condições:
- Passos:
  1.
  2.
  3.
- Resultado esperado:
- Resultado obtido:
- Status: Aprovado / Reprovado / Parcial
- Evidência (print, log, link):
```
